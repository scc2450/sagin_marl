# Paper Workspace

本目录保存论文写作所需的轻量源文件、可复现实验脚本和已注册证据表。
原始 `runs/`、checkpoint 和大体量日志不进入本目录。

This directory keeps paper-facing figure assets, reproducible plotting scripts,
and registered evidence tables. The manuscript text is primarily maintained in
Overleaf/cloud exports rather than treated as canonical in this repository.
Raw `runs/`, checkpoints, and large logs stay outside this tree.

## Directory Map

| Directory | 中文说明 | English role |
|---|---|---|
| `manuscript_overleaf/` | 投稿图、可编辑 PPT 图源和少量 Overleaf 辅助文件。正文以云端版本为准。 | Submission-facing figures, editable PPT sources, and limited Overleaf support files. The cloud manuscript is authoritative. |
| `reproduction/` | 论文图表生成脚本、复现实验说明和证据整理说明。 | Figure/table generation scripts and reproduction notes. |
| `evidence_tables/` | 从运行结果导出的 CSV/JSON 证据表和注册索引。 | Registered CSV/JSON evidence tables exported from selected runs. |

`figure_sources/` 已移除，因为其中剩余 PDF 与
`manuscript_overleaf/figures/` 中的当前采用图完全重复。当前约定是：
表格证据放在 `evidence_tables/`，生成代码放在 `reproduction/`，稿件实际引用图放在
`manuscript_overleaf/figures/`。本地 `main.tex` 和 section 正文不作为权威副本维护。

`figure_sources/` has been removed because its remaining PDFs were exact
duplicates of the manuscript-facing figures. The current convention is:
evidence tables live in `evidence_tables/`, generation code lives in
`reproduction/`, and figures referenced by the manuscript live in
`manuscript_overleaf/figures/`. Local `main.tex` and section text are not
maintained as authoritative copies.

## Figure Policy

系统图和方法图的可编辑 PowerPoint 源文件保存在
`manuscript_overleaf/figures/`，其中 `taskflow.pdf` 和 `obs_and_actor.pdf`
来自同一个 `obs_and_actor_20260825.pptx` 源文件。

Editable PowerPoint sources for the system and method figures are kept under
`manuscript_overleaf/figures/`. `taskflow.pdf` and `obs_and_actor.pdf` are
two exports from the same `obs_and_actor_20260825.pptx` source.

Section 5 的性能图由 `reproduction/*.py` 从 `evidence_tables/` 读取数据生成。
当前投稿稿件只保留 PDF 输出；PNG/SVG 或临时草图应作为本地 scratch 处理。

Section 5 performance figures are generated by `reproduction/*.py` from
`evidence_tables/`. The manuscript keeps only PDF outputs; PNG/SVG inspection
copies or draft panels should be treated as local scratch artifacts.

## Evidence Policy

`evidence_tables/registry_index.csv` 是定位表格证据的入口。最终正文数字应能追溯到
CSV/JSON 行、评估 seed、checkpoint 和远端 run 目录。

`evidence_tables/registry_index.csv` is the entry point for paper-facing
evidence. Final manuscript numbers should remain traceable to CSV/JSON rows,
evaluation seeds, checkpoints, and the original remote run directories.

Do not add raw episode dumps, checkpoints, or full run directories here unless
they have been intentionally reduced into paper-facing evidence tables.
